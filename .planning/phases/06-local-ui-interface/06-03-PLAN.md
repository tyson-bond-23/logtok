**api_tokenize handler:**
Accepts multipart form data with three possible input sources (per D-18):
1. `file_path` field (string) -- server reads file directly (best for large files, per CONTEXT.md)
2. `content` field (string) -- pasted text content
3. `file` field (uploaded file bytes) -- file picker or drag-and-drop

Processing logic:
- Load config: use `config::find_config()` then `config::load_config()`, or `LoktokConfig::default()`
- Create store: use `Store::with_passphrase()` with the session key from `AppState` (accessed via axum `State` extractor). Store dir should be a temp directory or CWD/.loktok.
- For file_path input: validate path is a regular file (T-06-02 threat mitigation), then use `process_file_with_config()` wrapped in `tokio::task::spawn_blocking()` (RESEARCH.md Pitfall 1). Write output to a temp file, read it back.
- For content input: write content to a temp file, process it, read back the tokenized output.
- For file upload: write uploaded bytes to a temp file, process it, read back.
- Return HTML fragment with the tokenized output in a `<pre>` block, plus a copy button and stats (tokens found count).
- On error, return an HTML fragment with error message styled with the error color.
- After successful tokenization with file_path, include a `HX-Trigger` response header with `{"addRecentFile": "the_path"}` so Alpine.js can update recent files list.

```rust
use axum::extract::{Multipart, State};
use axum::response::Html;
use std::sync::Arc;
use std::path::PathBuf;

use crate::ui::AppState;
use crate::config;
use crate::store::Store;

pub async fn api_tokenize(
    State(state): State<Arc<AppState>>,
    mut multipart: Multipart,
) -> Html<String> {
    // Parse multipart fields
    let mut file_path: Option<String> = None;
    let mut content: Option<String> = None;
    let mut file_bytes: Option<Vec<u8>> = None;

    while let Ok(Some(field)) = multipart.next_field().await {
        let name = field.name().unwrap_or("").to_string();
        match name.as_str() {
            "file_path" => { file_path = field.text().await.ok(); }
            "content" => { content = field.text().await.ok(); }
            "file" => { file_bytes = field.bytes().await.ok().map(|b| b.to_vec()); }
            _ => {}
        }
    }

    // Determine input source and process
    let session_key = state.session_key.clone();
    let result = tokio::task::spawn_blocking(move || {
        tokenize_input(file_path, content, file_bytes, &session_key)
    }).await;

    match result {
        Ok(Ok((output, stats))) => {
            Html(format!(
                "<div class='result-success'>\
                   <div class='result-stats'>{}</div>\
                   <div class='result-actions'>\
                     <button onclick='navigator.clipboard.writeText(this.closest(\".result-success\").querySelector(\"pre\").textContent)' class='btn-copy'>Copy</button>\
                   </div>\
                   <pre class='result-output'>{}</pre>\
                 </div>",
                stats,
                askama::filters::escape(&output, askama::filters::Html).unwrap_or_default()
            ))
        }
        Ok(Err(e)) => {
            Html(format!(
                "<div class='result-error'><p>{}</p></div>",
                askama::filters::escape(&e, askama::filters::Html).unwrap_or_default()
            ))
        }
        Err(e) => {
            Html(format!("<div class='result-error'><p>Processing failed: {}</p></div>", e))
        }
    }
}

fn tokenize_input(
    file_path: Option<String>,
    content: Option<String>,
    file_bytes: Option<Vec<u8>>,
    session_key: &str,
) -> Result<(String, String), String> {
    // Load config
    let cfg = if let Some(found) = config::find_config() {
        config::load_config(&found).unwrap_or_default()
    } else {
        config::LoktokConfig::default()
    };
    let detection_config = cfg.to_detection_config();

    // Create store with session key
    let store_dir = std::env::current_dir()
        .map_err(|e| format!("Cannot determine CWD: {}", e))?
        .join(".loktok");
    let store = Store::with_passphrase(&store_dir, session_key.to_string())
        .map_err(|e| format!("Store error: {}", e))?;

    // Create temp output file
    let temp_out = tempfile::NamedTempFile::new()
        .map_err(|e| format!("Cannot create temp file: {}", e))?;
    let temp_out_path = temp_out.path().to_path_buf();

    // Determine input file
    let input_path = if let Some(ref fp) = file_path {
        let p = PathBuf::from(fp.trim());
        // T-06-02: Validate path is a regular file
        let meta = std::fs::metadata(&p)
            .map_err(|e| format!("Cannot access file '{}': {}", fp, e))?;
        if !meta.is_file() {
            return Err(format!("Not a regular file: {}", fp));
        }
        p
    } else if let Some(ref text) = content {
        // Write pasted content to temp file
        let temp_in = tempfile::NamedTempFile::new()
            .map_err(|e| format!("Cannot create temp file: {}", e))?;
        std::fs::write(temp_in.path(), text)
            .map_err(|e| format!("Cannot write temp file: {}", e))?;
        temp_in.path().to_path_buf()
    } else if let Some(ref bytes) = file_bytes {
        // Write uploaded bytes to temp file
        let temp_in = tempfile::NamedTempFile::new()
            .map_err(|e| format!("Cannot create temp file: {}", e))?;
        std::fs::write(temp_in.path(), bytes)
            .map_err(|e| format!("Cannot write temp file: {}", e))?;
        temp_in.path().to_path_buf()
    } else {
        return Err("No input provided. Enter a file path, paste content, or upload a file.".to_string());
    };

    // Process
    crate::processor::process_file_with_config(
        &input_path,
        Some(&temp_out_path),
        65536,   // default block size
        true,    // quiet (no progress bar in server context)
        false,   // not dry run
        &detection_config,
        Some(&store),
        cfg.ttl_seconds(),
    ).map_err(|e| format!("Tokenization failed: {}", e))?;

    let output = std::fs::read_to_string(&temp_out_path)
        .map_err(|e| format!("Cannot read output: {}", e))?;

    let line_count = output.lines().count();
    let stats = format!("Tokenized {} lines", line_count);

    Ok((output, stats))
}
```

**api_detokenize handler:**
Accepts form data with `content` field (tokenized text to detokenize).
- Load the token store using the session key from AppState
- Call `detokenizer::detokenize()` with the loaded token mappings
- Return HTML fragment with detokenized output, stats (replaced/unresolved counts)

```rust
pub async fn api_detokenize(
    State(state): State<Arc<AppState>>,
    mut multipart: Multipart,
) -> Html<String> {
    let mut content: Option<String> = None;
    while let Ok(Some(field)) = multipart.next_field().await {
        if field.name() == Some("content") {
            content = field.text().await.ok();
        }
    }

    let Some(text) = content else {
        return Html("<div class='result-error'><p>No content provided</p></div>".to_string());
    };

    let session_key = state.session_key.clone();
    let result = tokio::task::spawn_blocking(move || {
        let store_dir = std::env::current_dir()
            .map_err(|e| format!("Cannot determine CWD: {}", e))?
            .join(".loktok");
        let store = Store::with_passphrase(&store_dir, session_key)
            .map_err(|e| format!("Store error: {}", e))?;
        let data = store.load()
            .map_err(|e| format!("Cannot load token store: {}. Tokenize first.", e))?;
        let result = crate::detokenizer::detokenize(&text, &data.token_to_value);
        Ok::<_, String>(result)
    }).await;

    match result {
        Ok(Ok(dr)) => {
            Html(format!(
                "<div class='result-success'>\
                   <div class='result-stats'>{} tokens replaced, {} unresolved</div>\
                   <div class='result-actions'>\
                     <button onclick='navigator.clipboard.writeText(this.closest(\".result-success\").querySelector(\"pre\").textContent)' class='btn-copy'>Copy</button>\
                   </div>\
                   <pre class='result-output'>{}</pre>\
                 </div>",
                dr.replaced_count, dr.unresolved_count,
                askama::filters::escape(&dr.text, askama::filters::Html).unwrap_or_default()
            ))
        }
        Ok(Err(e)) => Html(format!("<div class='result-error'><p>{}</p></div>", e)),
        Err(e) => Html(format!("<div class='result-error'><p>Processing failed: {}</p></div>", e)),
    }
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser form -> /api/tokenize | User-provided file paths and text content |
| Server -> filesystem | Reading files specified by user in file_path field |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02 | Tampering | File path input | mitigate | Validate path with `std::fs::metadata().is_file()` before processing. Reject non-regular files (directories, symlinks, devices). Only 127.0.0.1 access (D-20). |
| T-06-05 | Denial of Service | File upload size | mitigate | axum Multipart has a default body limit. Set explicit limit of 50MB via `DefaultBodyLimit::max(50 * 1024 * 1024)` on the tokenize route if needed. File path input bypasses upload for large files. |
| T-06-06 | Tampering | XSS in tokenized output | mitigate | All output HTML-escaped via `askama::filters::escape` or manual `<>&"'` escaping before rendering in `<pre>` blocks. |
</threat_model>
