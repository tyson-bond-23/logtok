    ```rust
    fn main() -> Result<()> {
        let cli = Cli::parse();

        // Load config (D-07: walk up from CWD, or use --config override)
        let config = if let Some(config_path) = &cli.config {
            config::load_config(config_path)?
        } else if let Some(found) = config::find_config() {
            config::load_config(&found)?
        } else {
            LoktokConfig::default()
        };

        // Handle --reset-store: delete store and exit (D-14)
        if cli.reset_store {
            let store_dir = std::env::current_dir()?.join(".logtok");
            let store = store::Store::new(&store_dir)?;
            store.reset()?;
            eprintln!("logtok: token store reset");
            return Ok(());
        }

        // Require file for all other operations
        let file = cli.file.as_ref()
            .ok_or_else(|| anyhow::anyhow!("log file path is required (unless using --reset-store)"))?;

        // Validate input file
        let metadata = fs::metadata(file)
            .with_context(|| format!("Cannot access file: {}", file.display()))?;
        if !metadata.is_file() {
            anyhow::bail!("Not a regular file: {}", file.display());
        }
        if cli.block_size < 1024 || cli.block_size > 104_857_600 {
            return Err(TokeniserError::InvalidBlockSize { size: cli.block_size }.into());
        }

        // Build detection config from TOML
        let detection_config = config.to_detection_config();

        // Determine store directory (next to config file, or CWD/.logtok)
        let store_dir = std::env::current_dir()?.join(".logtok");

        // Load or create store (only if LOGTOK_KEY is set)
        // If LOGTOK_KEY is not set, proceed without store (in-memory only)
        let store_result = store::Store::new(&store_dir);

        // Run pipeline
        processor::process_file_with_config(
            file,
            cli.output.as_deref(),
            cli.block_size,
            cli.quiet,
            cli.dry_run,
            &detection_config,
            store_result.ok().as_ref(),
            config.ttl_seconds(),
        )?;

        Ok(())
    }
    ```

| Boundary | Description |
|----------|-------------|
| CLI args -> processor | User-provided file path and config path |
| config file -> detection | TOML config affects which patterns run |
| env var -> crypto | LOGTOK_KEY passphrase quality is user-controlled |
| store file -> token map | Encrypted blob loaded from disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-12 | I (Info Disclosure) | dry-run output | mitigate | KEY, PASS, CONN, JWT, PEM values shown as "(values hidden)" in dry-run. Other categories show truncated examples only. Output to stderr, never stdout. |
| T-02-13 | I (Info Disclosure) | store without LOGTOK_KEY | mitigate | If LOGTOK_KEY not set, store operations are skipped (in-memory only). No error thrown during normal tokenization -- tool degrades gracefully to non-persistent mode. |
| T-02-14 | T (Tampering) | config disable | accept | User can disable categories via config. This is an intended feature. If user disables all categories, output is untokenized -- this is user's explicit choice, not a security flaw. |
| T-02-15 | I (Info Disclosure) | .logtok directory | mitigate | Processor should create `.logtok/.gitignore` with `*` content to prevent accidental commit of store.enc. |
</threat_model>
