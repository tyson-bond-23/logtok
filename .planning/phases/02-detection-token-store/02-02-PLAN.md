       ```
       [4 bytes]   Magic: "LTOK"
       [1 byte]    Version: 0x01
       [16 bytes]  Salt (for Argon2 key derivation)
       [12 bytes]  Nonce (for AES-GCM)
       [N bytes]   Ciphertext (AES-GCM encrypted serde_json of TokenMapData, includes 16-byte auth tag)
       ```

       **Key derivation** (per D-11):
       ```rust
       use aes_gcm::{
           aead::{Aead, AeadCore, KeyInit, OsRng},
           Aes256Gcm, Nonce,
       };
       use argon2::Argon2;
       use rand::RngCore;

       const MAGIC: &[u8; 4] = b"LTOK";
       const VERSION: u8 = 0x01;
       const SALT_LEN: usize = 16;
       const NONCE_LEN: usize = 12;
       const HEADER_LEN: usize = 4 + 1 + SALT_LEN + NONCE_LEN; // 33 bytes

       fn derive_key(passphrase: &[u8], salt: &[u8]) -> Result<[u8; 32], crate::error::TokeniserError> {
           let mut key = [0u8; 32];
           Argon2::default()
               .hash_password_into(passphrase, salt, &mut key)
               .map_err(|e| crate::error::TokeniserError::StoreError {
                   message: format!("Key derivation failed: {}", e),
               })?;
           Ok(key)
       }
       ```

       **Load method** (returns empty TokenMapData if file doesn't exist -- first run):
       ```rust
       pub fn load(&self) -> Result<TokenMapData, crate::error::TokeniserError> {
           if !self.path.exists() {
               return Ok(TokenMapData::default());
           }
           let data = std::fs::read(&self.path).map_err(|e| {
               crate::error::TokeniserError::StoreError {
                   message: format!("Cannot read store file: {}", e),
               }
           })?;
           // Validate magic and version
           if data.len() < HEADER_LEN || &data[0..4] != MAGIC || data[4] != VERSION {
               return Err(crate::error::TokeniserError::StoreError {
                   message: "Invalid store file format".to_string(),
               });
           }
           let salt = &data[5..5 + SALT_LEN];
           let nonce_bytes = &data[5 + SALT_LEN..HEADER_LEN];
           let ciphertext = &data[HEADER_LEN..];
           let key = derive_key(self.passphrase.as_bytes(), salt)?;
           let cipher = Aes256Gcm::new(&key.into());
           let nonce = Nonce::from_slice(nonce_bytes);
           let plaintext = cipher.decrypt(nonce, ciphertext).map_err(|_| {
               crate::error::TokeniserError::StoreError {
                   message: "Decryption failed -- wrong LOGTOK_KEY or corrupted store file".to_string(),
               }
           })?;
           serde_json::from_slice(&plaintext).map_err(|e| {
               crate::error::TokeniserError::StoreError {
                   message: format!("Store data deserialization failed: {}", e),
               }
           })
       }
       ```

       **Save method** (atomic write via temp file + rename, per Pitfall 5):
       ```rust
       pub fn save(&self, data: &TokenMapData) -> Result<(), crate::error::TokeniserError> {
           // Load existing salt if store exists, else generate new
           let salt = if self.path.exists() {
               let existing = std::fs::read(&self.path).map_err(|e| {
                   crate::error::TokeniserError::StoreError {
                       message: format!("Cannot read existing store for salt: {}", e),
                   }
               })?;
               if existing.len() >= 5 + SALT_LEN {
                   let mut s = [0u8; SALT_LEN];
                   s.copy_from_slice(&existing[5..5 + SALT_LEN]);
                   s
               } else {
                   let mut s = [0u8; SALT_LEN];
                   rand::rng().fill_bytes(&mut s);
                   s
               }
           } else {
               let mut s = [0u8; SALT_LEN];
               rand::rng().fill_bytes(&mut s);
               s
           };

           let key = derive_key(self.passphrase.as_bytes(), &salt)?;
           let cipher = Aes256Gcm::new(&key.into());
           let nonce = Aes256Gcm::generate_nonce(&mut OsRng);

           let plaintext = serde_json::to_vec(data).map_err(|e| {
               crate::error::TokeniserError::StoreError {
                   message: format!("Serialization failed: {}", e),
               }
           })?;
           let ciphertext = cipher.encrypt(&nonce, plaintext.as_ref()).map_err(|_| {
               crate::error::TokeniserError::StoreError {
                   message: "Encryption failed".to_string(),
               }
           })?;

           // Build output: magic + version + salt + nonce + ciphertext
           let mut output = Vec::with_capacity(HEADER_LEN + ciphertext.len());
           output.extend_from_slice(MAGIC);
           output.push(VERSION);
           output.extend_from_slice(&salt);
           output.extend_from_slice(nonce.as_slice());
           output.extend_from_slice(&ciphertext);

           // Atomic write via temp file + rename (Pitfall 5)
           let tmp_path = self.path.with_extension("enc.tmp");
           std::fs::write(&tmp_path, &output).map_err(|e| {
               crate::error::TokeniserError::StoreError {
                   message: format!("Cannot write temp store file: {}", e),
               }
           })?;
           std::fs::rename(&tmp_path, &self.path).map_err(|e| {
               crate::error::TokeniserError::StoreError {
                   message: format!("Cannot finalize store file: {}", e),
               }
           })?;

           Ok(())
       }
       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LOGTOK_KEY env var -> key derivation | User-provided passphrase of unknown strength |
| .logtok.toml -> config parser | User-edited TOML file, may contain invalid regex patterns |
| store.enc file -> decryption | File on disk, could be tampered with or corrupted |
| filesystem -> store write | Process could be killed mid-write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | I (Info Disclosure) | store.rs key handling | mitigate | Key derived via Argon2id (memory-hard, GPU-resistant). Key never stored -- derived per session from env var. Key material zeroed after cipher creation (Rust drops). |
| T-02-05 | I (Info Disclosure) | store.rs nonce reuse | mitigate | Fresh random nonce via `Aes256Gcm::generate_nonce(&mut OsRng)` on every `save()`. Nonce stored alongside ciphertext. Never derived deterministically. |
| T-02-06 | T (Tampering) | store.enc file | mitigate | AES-GCM is authenticated encryption (AEAD). Any tampering with ciphertext, nonce, or salt causes decryption failure with clear error. Magic bytes + version detect corrupt/wrong files. |
| T-02-07 | I (Info Disclosure) | store.enc permissions | mitigate | Store file created in user-controlled `.logtok/` directory. On Unix, directory inherits user umask. Document that `.logtok/` should be in `.gitignore`. |
| T-02-08 | D (DoS) | store.rs Argon2 | accept | Argon2 key derivation is intentionally slow (~100ms). This is a security feature, not a bug. Acceptable for CLI tool startup. |
| T-02-09 | T (Tampering) | store.rs atomic write | mitigate | Write to `.enc.tmp` then rename. If process killed mid-write, only temp file is corrupted -- existing `store.enc` remains intact. |
| T-02-10 | I (Info Disclosure) | config.rs TOML | accept | Config file contains category names and custom regex patterns, not sensitive data. No secrets in TOML. |
| T-02-11 | I (Info Disclosure) | weak LOGTOK_KEY | accept | Argon2id makes brute force expensive even for weak passphrases. Adding minimum length validation would be a UX improvement but is not strictly necessary for ASVS L1. |
</threat_model>
